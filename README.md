MY PYTHON PROJECT


A short notes on my python project

Features :- It perform all the CRUD operations on file.

1) CREATE A FILE
2) REMOVE A FILE
3) UPDATE A FILE
4) DELETE A FILE


REQUIREMENTS :-
>Python 3.X
>Require python pacages listed in requirement.txt

Installation
Clone the repository:
git clone https://github.com/Utkarsh9793-03/FILE_HANDLING_PRJT.git
Go into the project folder:
cd YOUR_REPOSITORY
Install the required packages:
pip install -r requirements.txt
Usage

Run the project with:

python main.py
